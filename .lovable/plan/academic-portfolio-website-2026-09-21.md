# Academic Portfolio Website

## Goal
Create a polished, responsive single-page academic portfolio for Harun Chaudhari using the supplied biography and scholarly content.

## Build
- Establish a navy, charcoal, and parchment design system with elegant serif headings and readable sans-serif body text.
- Create a sticky responsive navigation bar with smooth section links.
- Build the home, bio-data, doctoral research, teaching experience, resources, and contact sections.
- Add functional interactions for mobile navigation, placeholder document downloads, CV download, and contact-form feedback.
- Add route-specific page metadata and accessible focus, reduced-motion, and responsive behavior.
- Verify the finished page in desktop and mobile layouts.

## Technical details
- Keep the experience at `/` as a single scrolling portfolio, as requested.
- Use semantic Tailwind design tokens from the global stylesheet and React components for repeated UI patterns.
- Use a locally generated scholarly library image as supporting visual material.
